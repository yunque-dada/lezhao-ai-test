3你玩过万花筒吗？

万花筒是一种光学玩具，里面有多彩的图案。
转动万花筒，图案会不断变化，非常漂亮！

今天我们就要用Python来创造数字万花筒！

4让我们开始吧！

打开Python（IDLE或Thonny），导入需要的模块

import turtle

t = turtle.Turtle()
t.speed(0)
turtle.bgcolor("black")
t.pensize(2)

6先画一个简单的图形

正八边形有8条边，每次右转45度，边长100像素

for side in range(8):
    t.forward(100)
    t.right(45)

7给图形穿上彩色外衣

每次画边之前，从颜色列表中随机选一个颜色

for side in range(8):
    t.color(random.choice(colors))
    t.forward(100)
    t.right(45)

8转起来！变成万花筒

画完一个八边形后，将海龟旋转一个小角度（比如10度），再画下一个八边形

for times in range(36):
    for side in range(8):
        t.color(random.choice(colors))
        t.forward(100)
        t.right(45)
    t.right(10)

9让图案有层次感

每次画完一圈，把边长增加一点点，形成螺旋上升的效果

size = 50
for times in range(30):
    for side in range(8):
        t.color(random.choice(colors))
        t.forward(size)
        t.right(45)
    t.right(15)
    size = size + 3

10一起来运行吧！

这是我们这节课的最终代码（可以直接复制运行）

import turtle
import random

t = turtle.Turtle()
t.speed(0)
turtle.bgcolor("black")
t.pensize(2)

colors = ["red", "orange", "yellow", "green", "blue", 
          "purple", "pink", "cyan", "magenta"]

size = 20
for times in range(72):
    t.color(random.choice(colors))
    for side in range(30):
        t.forward(size)
        t.right(91)
        size += 1
    t.right(5)

t.hideturtle()
turtle.done()

11变身小小艺术家

修改下面这些参数，看看图案有什么变化：

外循环次数： 72 → 36 或 120
内循环次数： 30 → 10 或 50
旋转角度： 5 → 10 或 2
颜色列表： 添加自己喜欢的颜色

和同桌比一比，谁画出的图案最漂亮！
